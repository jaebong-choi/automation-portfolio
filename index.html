자동화 실적

유학 기업 재직 중 실무로 만든 자동화입니다. 행을 누르면 검증 방법이 열립니다.

자동화 대상사용 도구Before → After절감 효과
인스타 카드뉴스(1080×1350) 세트 제작 Claude 스킬 + Python/Playwright (HTML→PNG 렌더링) Before → After수작업 3~4시간 → 1시간 절감세트당 2~3시간

비자·정책 뉴스를 카드뉴스 세트로 만드는 작업을 스킬로 고정했습니다. 브랜드 색·레이아웃 규칙을 스킬에 담아 두고 HTML로 조판한 뒤 Playwright로 렌더링합니다. 발행 전에 수치·날짜를 원문과 대조하고 렌더링 결과를 전수 확인합니다.

국가별 유학 안내 사이트 데이터 구축·배포 Claude Cowork (조사·교차검증) + Claude Code (구현) Before → After수작업 3일 → 4~5시간 절감사이트 5종 배포 완주

국가별 진학 요건·학비 데이터를 Cowork로 수집하고, 각 대학 공식 페이지와 대조해 검증한 뒤 Claude Code로 구현해 GitHub Pages에 배포했습니다. 미국·영국·호주·캐나다 진단 사이트와 허브까지 5종을 완주했습니다.

네이버 블로그 원고 생산 (검수 포함) Claude 스킬 (SEO 구조화 + 문체 검수) Before → After편당 2~3시간 → 30분 절감편당 약 2시간

네이버 SEO 구조와 문체 규칙을 스킬로 만들어 초안을 뽑고, AI 문형을 걸러내는 검수 단계를 거쳐 발행합니다. 인용하는 수치는 출처 페이지에서 직접 확인합니다.

쇼츠용 9:16 데이터 그래픽 제작 Claude 스킬 + Playwright 렌더링 Before → After컷당 2~3시간 → 30분 절감컷당 약 2시간

쇼츠 대본의 화면 지시를 표·그래프·타임라인 카드(1080×1920)로 변환합니다. 서술형 정보를 데이터 그래픽으로 재구성하고, 수치는 대본의 출처와 대조한 뒤 렌더링합니다.

출국 전 오리엔테이션 반복 안내 Notion 시스템 (영국·캐나다·호주 3개국) Before → After구두 안내 1시간/건 → 셀프 안내 절감건당 40분

상담원이 매번 1시간씩 구두로 반복하던 출국 전 안내를 국가별 Notion 페이지로 시스템화했습니다. 학생이 스스로 읽고 확인 사항만 상담으로 남겨, 건당 확인 시간은 20분 수준으로 줄었습니다.
