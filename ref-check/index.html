원고의 인용

문헌 A에 따르면 조사 대상국의 유학생 수는 2022년 기준 약 64만 명으로 집계됐다.

원문 (문헌 A, p.12)

"…2022년 총 등록 유학생은 639,412명으로 전년 대비 4.2% 증가…"

판정 근거: 639,412명을 "약 64만 명"으로 표기 — 반올림 범위 내 일치.
인용 2수치 불일치

원고의 인용

문헌 B는 졸업 후 현지 취업률이 41%에 이른다고 보고했다.

원문 (문헌 B, p.7)

"…졸업 6개월 시점의 취업률은 14%였으며, 3년 추적 시 41%까지 상승…"

판정 근거: 원고는 3년 추적치(41%)를 즉시 취업률처럼 인용 — 시점 조건이 누락된 수치 왜곡.
인용 3연도 오류

원고의 인용

해당 제도는 2019년 도입 이후 지원자가 두 배로 늘었다(문헌 C).

원문 (문헌 C, p.3)

"…2021년 제도 도입 후 2개 학년도 만에 지원자 수가 약 2배가 되었다…"

판정 근거: 도입 연도가 원문과 다름 (2021 → 2019로 오기).
인용 4일치

원고의 인용

문헌 D는 언어 요건 완화가 중도 이탈률 상승과 상관을 보였다고 분석했다.

원문 (문헌 D, p.21)

"…입학 언어 요건을 완화한 기관군에서 1학년 중도 이탈률이 유의하게 높았다…"

판정 근거: 원문의 상관 분석 결과를 조건 왜곡 없이 인용.
인용 5원문에 없는 주장

원고의 인용

문헌 E는 장학금 확대가 가장 효과적인 유치 수단이라고 결론지었다.

원문 (문헌 E, p.30)

"…장학금은 여러 요인 중 하나로, 단독 효과를 분리하기 어렵다는 한계가 있다…"

판정 근거: 원문은 효과 분리의 한계를 언급 — "가장 효과적"이라는 결론은 원문에 존재하지 않음.
인용 6요확인

원고의 인용

문헌 F에 따르면 응답 대학의 과반이 전담 조직을 운영 중이다.

원문 (문헌 F, p.9)

"…응답 기관의 48%가 전담 부서 또는 겸임 인력을 두고 있다고 답했다…"

판정 근거: 48%를 "과반"으로 표현 + "겸임 인력"을 "전담 조직"에 포함 — 저자 확인 필요.

작동 방식

사람이 하던 전수 대조를 3단계 리포트로 바꿉니다.

  1. 인용 추출원고에서 인용 문장과 출처 표기를 목록으로 뽑는다
  2. 원문 대조참고문헌의 해당 구절을 찾아 나란히 놓고 수치·연도·주장을 비교한다
  3. 불일치 리포트일치/불일치/요확인으로 판정하고 근거를 한 줄씩 남긴다 — 최종 판단은 사람이 한다

이 페이지의 원고와 문헌 A~F는 워크플로를 보여주기 위해 만든 가상 샘플입니다. 실제 검수에서는 Claude에 원고와 참고문헌 파일을 제공해 같은 형식의 리포트를 생성하고, 불일치 항목만 사람이 원문을 열어 최종 확인합니다.
